🛠️ KEEP THIS IN VIEW · THE DIAGNOSTIC ORDER

tamen test (→ concessive) → causal-logic test (→ causal) → narrative test (→ historical) → indicative (→ temporal). Run it in order and no cum clause can hide from you.

✅ TRY IT · vocabulary
Which word means “finally, at last”?
✅ TRY IT · classify
Cum Rōmae erat, multa vīdit. (note the mood)

Write your own: compose one Latin sentence with a concessive cum clause — use tamen in the main clause. Then reveal one correct version.

Cum aeger esset, tamen laborābat. — “Although he was sick, he nevertheless kept working.” The imperfect subjunctive esset plus tamen in the main clause makes it unmistakably concessive. If you left out tamen, a reader could take it as causal or historical — the marker is what fixes the meaning.
